## 📌 Sobre o site

Este portfólio pessoal foi desenvolvido com uma identidade visual inspirada no universo do **Minecraft**, trazendo elementos do jogo para uma experiência moderna, criativa e interativa.

A proposta é transformar a apresentação profissional em uma experiência temática, utilizando referências a blocos, inventários, construções e missões para organizar as informações.

O site apresenta minha trajetória acadêmica, tecnologias que estudo, projetos desenvolvidos e formas de entrar em contato comigo.

## 🎨 Identidade visual

O design utiliza uma estética inspirada no Minecraft, combinando elementos visuais do jogo com uma estrutura organizada e profissional.

Principais características:

- Cores predominantes em verde e preto.
- Elementos gráficos inspirados em blocos e pixel art.
- Tipografia temática.
- Animações e efeitos visuais.
- Transições e interações durante a navegação.
- Interface organizada e adaptável a diferentes dispositivos.

## ⚙️ Tecnologias utilizadas

O desenvolvimento do site utiliza tecnologias fundamentais para aplicações web:

- **HTML5:** estruturação do conteúdo.
- **CSS3:** identidade visual, estilização, responsividade e animações.
- **JavaScript:** interatividade e funcionalidades.
- **Google Fonts:** personalização da tipografia.
- **Font Awesome:** elementos gráficos e ícones.

## 🎯 Objetivo do projeto

O principal objetivo deste projeto é construir uma apresentação profissional que represente minha personalidade, criatividade e interesse pela tecnologia.

Além de funcionar como meu portfólio, o site demonstra meus conhecimentos em desenvolvimento web e minha capacidade de transformar uma ideia em uma experiência digital.
